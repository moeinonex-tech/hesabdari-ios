# راه‌اندازی ساخت iOS بدون مک

اپ روی مک‌های ابری GitHub (`macos-26`) ساخته، امضا و به TestFlight فرستاده می‌شود. برای این کار به یک مرورگر و آیفون نیاز دارید.

> **امنیت:** کلید API، فایل `.p8`، Issuer ID و Key ID را هیچ‌وقت در چت نفرستید. فقط خودتان آن‌ها را در GitHub Secrets وارد کنید.

---

## ۱. GitHub

1. یک مخزن **خصوصی** بسازید، مثلاً به نام `hesabdari-ios`، بدون README.
2. GitHub را به Claude وصل کنید. بعد نام مخزن را به من بگویید تا فایل‌ها را خودم push کنم.
   - راه جایگزین: فایل‌های zip را در صفحه‌ی مخزن، از مسیر **Add file → Upload files**، با کشیدن و رها کردن آپلود کنید.
   - پوشه‌ی `.github` هم باید آپلود شود.

**هزینه‌ی دقیقه‌ها:** در مخزن خصوصی، هر دقیقه‌ی macOS ده دقیقه حساب می‌شود. پس از ۲۰۰۰ دقیقه‌ی رایگان ماهانه، حدود ۲۰۰ دقیقه‌ی macOS می‌ماند.

- یک اجرای تست تنها چند دقیقه طول می‌کشد.
- ساخت و ارسال به TestFlight احتمالاً ۱۵ تا ۲۵ دقیقه طول می‌کشد. این عدد تخمین است و بعد از اولین اجرا دقیقش را می‌گویم.
- ارسال به TestFlight فقط وقتی انجام می‌شود که خودتان روشنش کنید (مرحله‌ی ۴).

## ۲. Apple Developer — شناسه‌ها

1. **Team ID:** در developer.apple.com/account بخش **Membership details** را باز کنید. Team ID یک رشته‌ی ۱۰ حرفی است.
2. **Bundle ID:**
   - مسیر: **Certificates, Identifiers & Profiles → Identifiers → +**
   - نوع را **App IDs**، سپس **App** انتخاب کنید.
   - حالت Explicit را بزنید و یک شناسه‌ی یکتا بنویسید، مثلاً `uk.yourname.hesabdari`.
   - فعلاً قابلیت خاصی لازم نیست. iCloud را در فاز بعد اضافه می‌کنیم. Face ID قابلیت جداگانه نمی‌خواهد.

## ۳. App Store Connect

1. **ساخت اپ:**
   - مسیر: **Apps → + → New App**
   - Platform را iOS بگذارید.
   - Name: «دفتر حساب». اگر این نام قبلاً گرفته شده باشد، نام دیگری بگذارید. نامی که روی گوشی نمایش داده می‌شود جداست و همان «دفتر حساب» می‌ماند.
   - Primary Language را Persian بگذارید.
   - Bundle ID: همانی که در مرحله‌ی ۲ ساختید.
   - SKU: هر رشته‌ای، مثلاً `hesabdari-ios`.
2. **کلید API:**
   - مسیر: **Users and Access → Integrations → App Store Connect API → Team Keys → +**
   - Access باید **Admin** باشد. ساخت گواهی امضا در فضای ابری بدون این دسترسی کار نمی‌کند.
   - فایل `.p8` فقط یک بار دانلود می‌شود. آن را جای امن نگه دارید.
   - **Issuer ID** و **Key ID** را از همین صفحه بردارید.
3. اگر App Store Connect توافق‌نامه‌ی جدیدی برای پذیرفتن نشان داد، آن را بپذیرید. توافق‌نامه‌ی پذیرفته‌نشده ارسال را متوقف می‌کند.

## ۴. GitHub Secrets و Variables

مسیر در مخزن: **Settings → Secrets and variables → Actions**

**Secrets** (تب Secrets):

| نام | مقدار |
|---|---|
| `APPLE_TEAM_ID` | Team ID |
| `ASC_KEY_ID` | Key ID |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_KEY_P8` | فایل `.p8` را با Notepad باز کنید و **کل متن** را بچسبانید، از جمله خط‌های `BEGIN` و `END` |

**Variables** (تب Variables):

| نام | مقدار |
|---|---|
| `BUNDLE_ID` | Bundle ID مرحله‌ی ۲ |
| `TESTFLIGHT_ENABLED` | `true` |

## ۵. اجرا

1. در تب **Actions**، workflow به نام **iOS** را انتخاب کنید و **Run workflow** را بزنید.
2. ابتدا تست‌های هسته اجرا می‌شوند:
   - ۲۵٬۹۳۳ روز تقویم جلالی
   - ۲۲ سناریوی کمیسیون با قاعده‌ی مصوب
   - اگر حتی یک عدد با طلایی‌های فاز ۱ فرق کند، ساخت متوقف می‌شود.
3. سپس اپ ساخته، امضا و به App Store Connect فرستاده می‌شود.
4. پردازش در اپل معمولاً ۱۰ تا ۳۰ دقیقه طول می‌کشد.
5. در App Store Connect، در بخش **TestFlight → Internal Testing**، خودتان را به‌عنوان تستر اضافه کنید.
6. اپ **TestFlight** را روی آیفون نصب کنید.

آیفون باید **iOS 26** داشته باشد.

## اگر خطا داد

لینک اجرای ناموفق در تب Actions را برای من بفرستید. لاگ‌ها شامل secrets نیستند، چون GitHub آن‌ها را با `***` می‌پوشاند.

**احتمال خطا در اولین اجرا واقعی است:**

- **کد Swift:** کد Swift در محیط من کامپایل نشده، چون کامپایلر Swift در دسترس نبود. منطق آن با یک نسخه‌ی آینه‌ای در JavaScript روی طلایی‌ها چک شد (۲۰۱۴ از ۲۰۱۴).
- **امضای ابری:** ممکن است در اولین بار به یکی از این‌ها گیر کند:
  - توافق‌نامه‌ی پذیرفته‌نشده
  - سقف تعداد گواهی‌ها
  - نقش کلید API که Admin نیست
